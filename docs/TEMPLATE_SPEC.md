# Word 模板规范

1. 模板格式必须为 `.docx`，不得上传带宏的 `.docm`。
2. 自动填充位置使用 Word 纯文本内容控件，`Tag` 是稳定字段编码，`Alias` 是中文说明。
3. `Tag` 必须全局唯一并使用大写下划线命名，例如 `PROJECT_NAME`、`FLOW_RATE`。
4. 不允许把一个标签拆成多个内容控件。重复内容应使用不同标签并由规则显式映射。
5. 首版支持正文、页眉和页脚内的纯文本内容控件；富文本、复选框和下拉内容控件不作为自动填充目标。
6. 模板发布前必须通过：ZIP/OOXML 结构、标签唯一、必填标签、测试填充和 LibreOffice 渲染检查。
7. 模板发布后不可覆盖。任何修改必须创建新版本，历史报告继续绑定原版本。

推荐首版标签：`PROJECT_NAME`、`SAMPLE_NAME`、`BATCH_NO`、`COLUMN_NAME`、`FLOW_RATE`、`LINEARITY_R`、`LOQ`。
